The unofficial Kick TV app for LG webOS can now find channels on Kick:

- **Search Kick** on the home screen finds public channels by part of a name, an `@name` or a `kick.com/…` link. Results show the display name, LIVE and verified labels, up to six per page. Selecting one opens that channel's live stream and replays without autoplay. A query with spaces that finds nothing is retried without spaces (`la cobra` finds `lacobra`), and an exact username missing from search is resolved directly.
- Searches start only when you confirm. Editing the text, closing the dialog or leaving the app cancels a pending search, and a late reply never replaces newer results or moves focus out of the text field.
- Remote input: Back first closes the TV's on-screen keyboard, then the dialog. Backspace outside a text field and Esc act as Back.
- The developer layout checker now separates painted overflow from scroll extent that paints nothing (Chromium 68's collapsed trailing margin), while clipped text, out-of-bounds and overlapping controls still fail.
- A [hardware acceptance protocol](https://github.com/JirakJ/kick-web-os-app/blob/main/docs/hardware-acceptance.md) and a Web Inspector soak sampler prepare the remaining physical-remote, Wi-Fi, Voice Guide and multi-hour checks.

Kick's search endpoint belongs to its website and is not a documented public API; it may change. Search requests go through the app's TV service with the existing TLS, size, time and concurrency limits and return only channel names and status, without images or media addresses.
