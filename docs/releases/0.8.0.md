Adds eight viewer features:

- Continue watching and replay resume/start-over, with bounded local history.
- Favorites with stable ordering, paging and visible-channel LIVE status.
- Auto and validated fixed-quality renditions; pause and replay position survive changes.
- Fresh-source reconnect with bounded retries, explicit retry and pause/cancellation handling.
- Local saved-channel and replay-title search, viewing filters and deterministic ordering.
- Go to time and deliberate ten-minute seek previews with Confirm/Cancel.
- Viewer-initiated official stable-release checks and supported manual update guidance.
- App-only larger text and high contrast, consistent focus and localized status labels.

TV acceptance found and fixed a webOS 5 zero-clock race: a second quality change
while paused could lose the requested replay position. Regression coverage and
native retesting now preserve it, including 2:03:04 through 720p, Auto and reconnect.

Verified on LG 55NANO863NA / webOS 5.6.2 / Chromium 68: real live and replay 1080p/60,
fixed 720p/60, restart/storage, native TV keyboard input, multi-hour seeking,
completion, a 55-second TV-only internet outage and bounded recovery. Sixteen
replay start/return and 50 pagination cycles kept catalog DOM/listener counts
stable; native decoder cleanup passed. All 13 locales pass 1,144 browser screens;
CI also covers Node.js 0.12.2 and 8.12.0, dependency audit and secret scanning.

The same app/service IDs preserve local data. Install the official IPK through
webOS Dev Manager or the existing Homebrew setup and verify SHA256SUMS. Keep
v0.7.5 for rollback. There is no automatic in-app installer.

Voice Guide is off and unchanged; audible output, physical handset input,
Wi-Fi/router restart, naturally expired sources, multi-hour soak and actual
4K/1440p decoding remain unverified. Native audio telemetry is active/unmuted.
