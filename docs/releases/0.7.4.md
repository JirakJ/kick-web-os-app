Security maintenance release for the webOS build tools, with fresh verification
on an LG 55NANO863NA running webOS 5.6.2. The player behavior is unchanged.

- Upgrade both `brace-expansion` dependency lines to 1.1.21 and 5.0.12, and
  `proxy-addr` to 2.0.8.
- Pin documented local security backports for `braces` and `sprintf-js`, whose
  fixes have no official release yet. Source commits, registry integrity,
  replacement-file checksums, archive checksums, licenses and a reproducible
  build recipe are included. These are local forks, not upstream releases.
- Add installed-dependency regressions for nested brace patterns, proxy trust
  boundaries and oversized numeric precision, including the minified sprintf
  bundle and uncaught asynchronous calls.
- Align app, service, package, lockfile and displayed versions to **0.7.4**.

**Validation:** clean npm 12 installation, full regression suite, byte-reproducible
backport archives, official webOS CLI package build, OSV and npm audit with no
reported vulnerabilities. The service integration checks also passed on the
TV's actual Node.js 8.12.0 runtime.

**TV checks:** Czech interface; home, replay catalog and player layout; real live
and replay playback; native 1080p/60 telemetry; pause, paused seeking and rapid
seek input; remote key navigation; replay pagination; automatic control hiding;
decoder cleanup on return. Native telemetry reported an active unmuted audio
track; audible sound was not independently checked. Multi-hour playback,
actual 4K playback and webOS 3.5 hardware remain unverified.

**Installation:** use `com.jakubjirak_0.7.4_all.ipk` and verify the attached
`SHA256SUMS`. Updates from 0.7.2 and 0.7.3 retain the same app/service identity
and its stored data. Versions 0.7.1 and earlier used `cz.jirak.kicktv`; the new
app installs alongside that identity and does not automatically migrate data.
The one-time history transfer performed during this device check is not an
automatic migration feature.
