Changes the application/package ID to **`com.jakubjirak`** and its Luna service ID to **`com.jakubjirak.service`**.

- Updates application and service manifests, service registration, and all UI service calls together.
- Names the installation package `com.jakubjirak_0.7.2_all.ipk`; release publishing derives this name from the app manifest.
- Adds checks that the manifests, service registration and UI requests agree on the new identity.
- Retains the Node.js 0.12.2 / older webOS compatibility fixes from 0.7.1.

**Installation:** this ID is different from `cz.jirak.kicktv` used in 0.7.1 and earlier. The new application installs separately and starts with its own recent channels and replay history. Existing data stays with the old application; no automatic migration is performed. Both can be installed at the same time.

**Validation:** full local regression suite, actual Node.js 0.12.2 and 8.12.0 service integration checks, and the official webOS CLI package build. CI repeats the tests before publishing the exact tested artifact and SHA256SUMS. On-device installation, native playback and layout on LG UJ6307 / webOS 3.5 remain unverified.
